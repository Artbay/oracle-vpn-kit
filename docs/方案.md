# 甲骨文云（Oracle Cloud）自建个人 VPN 方案

> 所有值均为占位符或 `.env` 变量名（`<VPS_IP>`、`HY2_PORT`、`cdn.example.com` 等），真实值只在你本地 `.env` 与服务器上。

## 1. 目标与背景

- 机器：甲骨文云 Always Free 的免费 VM（1 vCPU / 1 GB 内存级别即可），Ubuntu LTS x86_64，区域 `<REGION>`。
- 常见痛点：部分国内家庭宽带对境外 VPS 公网 IP 的 **TCP 不通**，但 **UDP 正常**；手机流量下各协议可能都可用。
- 思路：
  1. **UDP 协议为主**：Hysteria2（混淆 + 端口跳跃）与 TUIC v5。
  2. **CDN 兜底 TCP**：Cloudflare Tunnel 把 `cdn.example.com` 接到 VPS 本机 WS 入站，客户端连的是 Cloudflare 边缘而非 VPS IP。
  3. **直连 TCP 保留**：Reality / XHTTP+Reality，在 TCP 未被封的网络下延迟最低。

## 2. 端口与组件

端口都是 `.env` 变量，`scripts/gen_secrets.sh` 会随机生成（`XHTTP_PORT` 默认 443）。

| 组件 | 监听 | 外部可达 | 说明 |
|---|---|---|---|
| hysteria-server | UDP `HY2_PORT` | 是 | salamander 混淆、自签证书 CN=`HY2_SNI`、伪装 https://`HY2_SNI` |
| iptables nat | UDP `HY2_HOP_START`-`HY2_HOP_END` → `HY2_PORT` | 是 | Hy2 端口跳跃（区间**不含** TUIC 端口） |
| tuic-server | UDP `TUIC_PORT` | 是 | h3、bbr、0-RTT，复用 Hy2 证书，独立用户 `tuic` |
| xray | TCP `REALITY_PORT` | 是 | VLESS + Reality + xtls-rprx-vision |
| xray | TCP `XHTTP_PORT` | 是 | VLESS + XHTTP(mode auto) + Reality |
| xray | `127.0.0.1:WS_LOCAL_PORT` | 否 | VLESS + WS，无 TLS，仅供 cloudflared 回源 |
| cloudflared | 仅出站 | — | 本地管理命名隧道，`CDN_DOMAIN` → `http://127.0.0.1:WS_LOCAL_PORT`，其余 404 |
| 订阅服务 | TCP `SUB_PORT` | 是 | python http.server，`nobody` 用户，秘密路径 `/<SUB_TOKEN>/` |

### OCI 安全列表（入站）

- TCP：22、`XHTTP_PORT`、`REALITY_PORT`、`SUB_PORT`
- UDP：`HY2_PORT`、`HY2_HOP_START`-`HY2_HOP_END`、`TUIC_PORT`
- ICMP（可选）

OCI 的 Ubuntu 镜像自带 iptables 规则（`INPUT ... REJECT`），脚本用 `iptables -I INPUT 1` 在 REJECT 前插入放行，并 `netfilter-persistent save` 持久化。**安全列表与主机 iptables 两层都要放行。**

## 3. 部署步骤

前置：`git clone` 本仓库到服务器，`chmod +x scripts/*.sh tools/*.py`，`cp .env.example .env` 并填写非随机项：`VPS_IP`、`VPS_IFACE`、`REALITY_SNI`、`HY2_SNI`、`CF_TUNNEL_NAME`、`CDN_DOMAIN`（自有域名，已托管到 Cloudflare）。

1. `bash scripts/gen_secrets.sh`：生成 UUID、shortId、路径、Hy2/TUIC 密码、订阅 token、全部随机端口；**只填空值/占位符，不覆盖已有值**，不回显秘密。然后按生成的端口配置 OCI 安全列表。
2. `sudo bash scripts/prepare_host.sh`：BBR、1 GB swap、iptables-persistent。
3. `sudo bash scripts/install_xray.sh`：首次会装好 xray 后因 Reality 密钥为空退出；再跑一次 `gen_secrets.sh` 补齐密钥对。
4. `sudo bash scripts/install_xray.sh`：渲染配置 → `xray run -test` 自检通过才替换 → 重启。
5. `sudo bash scripts/install_hysteria2.sh`：官方 get.hy2.sh 安装、自签证书、混淆。
6. `sudo bash scripts/setup_port_hopping.sh`：nat REDIRECT，检查 TUIC 端口不落在跳跃区间。
7. `sudo bash scripts/install_tuic.sh`：下载 tuic-server 官方二进制并 **sha256 校验**（建议在 `.env` 设 `TUIC_SHA256`）。
8. `sudo bash scripts/install_cloudflared_tunnel.sh`：官方 apt 源安装；`cloudflared tunnel login` 会给出授权链接，**由你本人在浏览器打开**；创建隧道、写 config、`tunnel route dns` 只新增这一条 proxied CNAME。完成后在 Cloudflare 面板确认 **SSL/TLS = Full**、**WebSockets 开启**。
9. `python3 tools/gen_subscription.py`：生成 `out/clash.yaml`、`out/links.txt`、二维码。可用 `mihomo -t -f out/clash.yaml` 校验。
10. `sudo bash scripts/serve_subscription.sh`：发布到 `/var/www/sub/<SUB_TOKEN>/`，根目录放空 `index.html` 防止目录列出。

### 可选：Cloudflare 优选 IP

用 CloudflareST 在**你自己的网络**下测出延迟最低的 Cloudflare 入口 IP，填到 `.env` 的 `CF_PREFERRED_IPS=<CF_IP_1>,<CF_IP_2>`，重新生成订阅即可得到 `<NODE_PREFIX>-CDN-1..N`：

- `server` = 优选 IP，`servername`(SNI) 与 WS `Host` 仍为 `CDN_DOMAIN`；
- 入口在离你较近的 Cloudflare 边缘，**出口仍是 VPS**（访问网站看到的仍是 VPS IP）；
- 优选 IP 会随时间变差，定期重测替换。详见 [03_客户端使用](03_客户端使用.md)。

## 4. 客户端

- **Clash Verge Rev（Mihomo 内核）**：导入订阅 URL `http://<VPS_IP>:<SUB_PORT>/<SUB_TOKEN>/<SUB_FILE_NAME>`。
  - 更新订阅前先把代理模式切到 **DIRECT/关闭系统代理**，否则走旧节点拉订阅可能失败。
  - 只用浏览器时 **不需要开 TUN**，系统代理即可。
- **Shadowrocket**：扫 `out/qr_*.png` 或导入 `out/links.txt`（格式见 `templates/share-links.md`）。
- 节点推荐顺序：**Hy2 → TUIC → CDN 优选 IP → CDN → XHTTP → Reality**。

## 5. 经验与排障

| 现象 | 原因 / 处理 |
|---|---|
| 家宽下 Reality、XHTTP、订阅都超时，手机流量正常 | 网络对 VPS IP 封 TCP。改用 Hy2/TUIC（UDP）或 CDN 节点；订阅可临时用手机热点更新 |
| Hy2 某段时间不通 | UDP 单端口被 QoS/干扰。用端口跳跃 + salamander 混淆；或切 TUIC/CDN |
| Reality/Hy2 特征被干扰 | 多协议并存，客户端按顺序切换；Reality 目标站选支持 TLS1.3+H2 的大站 |
| 测试结果混乱 | 测试前**退出其它 VPN/加速器客户端**，避免路由/TUN 冲突 |
| 更新订阅失败 | 先切 DIRECT 再更新；或检查 `SUB_PORT` 是否被封（TCP 被封时同样受影响） |
| CDN 节点 404 | 检查 WS path 与 Host；cloudflared `ingress` 主机名是否一致；面板 WebSockets 是否开启 |
| CDN 节点 525/526 | 检查 SSL 模式（本方案用 Full），不要用 Flexible |
| Hy2 跳跃端口不通 | OCI 安全列表与主机 iptables 都需放行跳跃区间；`iptables -t nat -S PREROUTING` 看规则；网卡名是否为 `VPS_IFACE` |
| TUIC 连不上 | 确认 `TUIC_PORT` 不在跳跃区间内（否则被重定向到 Hy2）；客户端 `skip-cert-verify: true`（自签证书） |
| 公网 IP 变了 | 临时 IP 会变：改 `.env` 的 `VPS_IP` → 重新生成订阅 → `serve_subscription.sh`；CDN 节点不受影响 |
| 某些网络对 TLS 做中间人 | Reality 会报 "received real certificate"，属本地网络问题，换 UDP/CDN 节点 |

常用检查：

```bash
systemctl status xray hysteria-server tuic-server cloudflared clash-sub
ss -lntup | grep -E 'xray|hysteria|tuic|python3'
journalctl -u hysteria-server -u tuic-server -n 50 --no-pager
iptables -S INPUT; iptables -t nat -S PREROUTING
```

## 6. 回滚

所有脚本修改前都会备份为 `<文件>.bak-YYYYmmdd-HHMMSS`。

- **TUIC**：`systemctl disable --now tuic-server`；删除 `/etc/systemd/system/tuic-server.service`；恢复 `/etc/iptables/rules.v4.bak-*` 后 `iptables-restore < /etc/iptables/rules.v4`。
- **端口跳跃**：`iptables -t nat -D PREROUTING -i <VPS_IFACE> -p udp -m udp --dport <HY2_HOP_START>:<HY2_HOP_END> -j REDIRECT --to-ports <HY2_PORT>`，再 `netfilter-persistent save`。
- **Hysteria2**：`systemctl disable --now hysteria-server`；恢复 `/etc/hysteria/config.yaml.bak-*`。
- **Xray**：`cp /usr/local/etc/xray/config.json.bak-<时间> /usr/local/etc/xray/config.json && systemctl restart xray`。
- **CDN 隧道**：
  1. `systemctl disable --now cloudflared`；
  2. `cloudflared tunnel route` 不会自动删 DNS：在 Cloudflare 面板删除该 CNAME；`cloudflared tunnel delete <隧道名>`；
  3. 订阅里去掉 CDN 节点并重新发布。
- **订阅**：`/var/www/sub/<SUB_TOKEN>/<SUB_FILE_NAME>.bak-*` 覆盖回去。

## 7. 安全注意

- `.env`、`out/`、证书私钥、cloudflared 凭据（`cert.pem`、`<隧道ID>.json`）都**不入库、不外发**，权限 600。
- 分享链接、二维码、订阅 URL 都含登录凭据：**只发给自己**，不要贴在聊天/群里。
- 订阅走明文 HTTP，安全性完全依赖长随机路径；泄露就立刻换 `SUB_TOKEN`（必要时连同 UUID/密码一起轮换）。
- Cloudflare：只新增隧道用的那一条 proxied CNAME，**不要改动 zone 里已有的其它记录和设置**。
- 只用于个人日常浏览；**不要与其它业务共用同一出口**。
- 不要为了绕过限速随意更换 IP 或叠加代理。
- 二进制只从官方来源安装（XTLS/Xray-install、get.hy2.sh、EAimTY/tuic Release + sha256、pkg.cloudflare.com）。
