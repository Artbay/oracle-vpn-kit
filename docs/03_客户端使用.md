# 03 客户端使用

> 订阅 URL、分享链接、二维码都含登录凭据：**只发给自己，不要转发、不要贴到群里或聊天里**。

## 0. 测试前先做

- **退出其它 VPN/加速器客户端**（包括其它商业 VPN、公司 VPN、游戏加速器），它们会抢路由或 TUN，导致测试结果混乱。
- 一台设备同一时间只开一个代理客户端。

## 1. 节点怎么选（推荐顺序）

节点名前缀由 `.env` 的 `NODE_PREFIX` 决定，下表以默认 `MyVPN` 为例。

| 顺序 | 节点 | 适用场景 |
|---|---|---|
| 1 | `MyVPN-Hy2` | 首选。UDP，家宽对 VPS IP 封 TCP 时仍可用 |
| 2 | `MyVPN-TUIC` | Hy2 不稳时的 UDP 备选 |
| 3 | `MyVPN-CDN-1..N` | UDP 都不行时；入口是你测出的 Cloudflare 优选 IP |
| 4 | `MyVPN-CDN` | 同上，入口用域名解析，不依赖优选 IP |
| 5 | `MyVPN-XHTTP` | 网络对 VPS IP 的 TCP 不封时，延迟低 |
| 6 | `MyVPN-Reality` | 同上，备选 |

CDN 节点的**入口**在离你较近的 Cloudflare 边缘，但**出口仍是你的 VPS**，网站看到的是 VPS 的 IP。

## 2. Windows：Clash Verge Rev（Mihomo 内核）

下载：官方仓库 <https://github.com/clash-verge-rev/clash-verge-rev/releases>（Windows x64 选 `Clash.Verge_<版本>_x64-setup.exe`；系统缺 WebView2 时选 `fixed_webview2` 版本）。

1. **导入订阅**：左侧 **订阅（Profiles）** → 顶部输入框粘贴订阅 URL `http://<VPS_IP>:<SUB_PORT>/<SUB_TOKEN>/<SUB_FILE_NAME>` → **导入** → 点击该订阅使其成为当前配置。
2. **更新订阅时先切 DIRECT**：在 **代理（Proxies）** 页把模式切到 **直连（Direct）**，或先关掉「系统代理」，再在订阅卡片上右键 **更新**。否则客户端可能通过已失效的旧节点去拉订阅而失败。更新完再切回 **规则**。
3. **选节点**：**代理** 页 → 策略组「节点选择」→ 按上表顺序选。
4. **测延迟**：策略组右上角的闪电/测速按钮；超时或红色的跳过。注意：延迟测试只测到测速 URL 的握手，**以实际打开网页为准**。
5. **模式**：
   - **规则（Rule）**：推荐。订阅里内置了简单规则（局域网、`.cn`、常见国内站点直连，其余走「节点选择」）。
   - **全局（Global）**：所有流量走代理，临时排查用。
   - **直连（Direct）**：全部不走代理，更新订阅时用。
6. **系统代理 vs TUN**：只用浏览器上网时，打开 **系统代理** 即可，**不需要开 TUN（虚拟网卡）**；只有不走系统代理的程序（部分游戏、命令行工具）才需要 TUN。
7. 服务端换 IP 或改配置后：**先切 DIRECT → 更新订阅 → 切回规则**。

## 3. iOS：Shadowrocket

1. **扫码**：首页右上角扫码图标，扫 `out/qr_<节点名>.png`（由 `tools/gen_subscription.py` 生成），每个节点一张；或在电脑上复制 `out/links.txt` 的链接，Shadowrocket 打开时会提示添加。
2. **或者添加订阅**：首页 **+** → 类型选 **Subscribe** → URL 填 `http://<VPS_IP>:<SUB_PORT>/<SUB_TOKEN>/v2ray.txt`（Base64 分享链接格式，Shadowrocket 原生支持，Hy2 端口跳跃、TUIC 等字段最完整）→ 保存；之后在首页下拉或长按订阅更新。也可以填 Clash 格式的 `<SUB_FILE_NAME>`，大部分节点能识别。
3. 选中节点 → 打开顶部开关连接；可点 **连通性测试** 测延迟。
4. **服务端改配置后**（换 IP、换密码、换端口跳跃区间等）：**删除旧节点**再重新扫码/更新订阅，避免旧节点残留导致选错。
5. 全局路由选 **配置（Config）** 即按规则分流；排查时可临时选 **代理（Proxy）**。

## 4. sing-box 客户端（iOS / macOS SFI·SFM、Android SFA、命令行）

`tools/gen_subscription.py` 会生成 `out/sing-box.json`（sing-box **1.12 及以上**的配置格式），`serve_subscription.sh` 会把它和 Clash 订阅一起发布。

- 官方客户端：iOS/macOS 在 App Store 搜 **sing-box**（认准开发者 SagerNet 的官方客户端，即 SFI/SFM）；Android 从官方仓库 <https://github.com/SagerNet/sing-box/releases> 下载 SFA；文档 <https://sing-box.sagernet.org/clients/>。
- **导入**：客户端 **Profiles（配置）** → **New Profile** → 类型选 **Remote（远程）** → URL 填 `http://<VPS_IP>:<SUB_PORT>/<SUB_TOKEN>/sing-box.json` → 打开 **Auto Update** → 保存；回到 Dashboard 选中这个配置，点 **Start**。
  - 也可以选 **Local** → 导入文件，把电脑上的 `out/sing-box.json` 传到手机（AirDrop/数据线，别经聊天软件）。
- **选节点**：Dashboard → **Groups** → 「节点选择」里选；默认是「自动选择」（按延迟自动挑）。
- **命令行**（Linux/macOS 桌面）：`sing-box check -c sing-box.json` 先校验，再 `sudo sing-box run -c sing-box.json`（TUN 需要管理员权限）；只想用本地代理可删掉 `tun-in` 入站，浏览器代理设为 `127.0.0.1:7890`。
- 配置里内置的分流和 Clash 订阅一致：局域网、`.cn` 和几个常见国内站点直连，其余走「节点选择」；DNS 国内域名走系统 DNS，其余经代理用 DoH。
- 注意：**sing-box 配置里只有 Hy2、TUIC、CDN 节点**。
  - sing-box 不支持 XHTTP 传输，所以没有 `XHTTP` 节点；
  - 也没有 `Reality` 节点：Xray-core v26.9.8 起，REALITY 服务端要求 ClientHello 带 X25519MLKEM768 密钥共享，而上游 sing-box（截至 1.14.x）的 REALITY 客户端会把它删掉，结果必然报 `reality verification failed`（sing-box issue #4520）。用的是已修复的分支时，在 `.env` 里加 `SINGBOX_REALITY=1` 再生成即可带上。
  - 需要 Reality / XHTTP 时用 Mihomo 内核（Clash Verge Rev，订阅里已加 `support-x25519mlkem768: true`）或 Xray 内核客户端（v2rayN 选 Xray 内核、v2rayNG）。
- 更新订阅时同样建议先停用或切直连，再刷新。

## 5. CloudflareST（CFST）测优选 IP（可选）

官方仓库：<https://github.com/XIU2/CloudflareSpeedTest>（新版程序名为 `cfst`）。

1. 从 [Releases](https://github.com/XIU2/CloudflareSpeedTest/releases) 下载对应系统的压缩包（如 `cfst_windows_amd64.zip`、`cfst_darwin_arm64.zip`）并解压。
2. **先关掉所有代理软件**（包括 Clash 的系统代理/TUN），在**你平时用的网络**（例如家宽）下运行。官方说明：如果平均延迟异常低（如 0.xx），说明测速走了代理。
3. 进入程序目录运行（Windows 在该目录打开 CMD；用相对路径，默认读取同目录的 `ip.txt`）：
   ```bash
   ./cfst                 # 默认参数
   ./cfst -tl 200 -dn 20  # 只要平均延迟 < 200ms 的，下载测速前 20 个（官方示例）
   ```
4. 结果显示在终端，并写入同目录 `result.csv`（列：IP 地址、已发送、已接收、丢包率、平均延迟、下载速度、地区码）。官方提示：用 Excel 打开中文可能乱码，用记事本或其它表格软件即可。
5. 挑 **丢包率 0、平均延迟最低、下载速度可接受** 的 2–3 个 IP（「地区码」是 Cloudflare 机房所在地的机场三字码）。
6. 填进 `.env`：`CF_PREFERRED_IPS=<CF_IP_1>,<CF_IP_2>,<CF_IP_3>` → `python3 tools/gen_subscription.py` → `sudo bash scripts/serve_subscription.sh`（或把新的 `out/` 文件传到服务器后再发布）→ 客户端更新订阅（先切 DIRECT）。
7. 每次测速随机抽 IP，结果每次都不同属正常；优选 IP 会随时间变差，**隔一段时间重测替换**。

## 6. 常见问题速查

| 现象 | 处理 |
|---|---|
| 家里宽带下所有 TCP 节点（XHTTP/Reality）和订阅都超时，手机流量正常 | 网络对 VPS IP 封了 TCP。用 Hy2/TUIC/CDN；订阅可用手机热点更新 |
| Hy2 突然不通 | 换 TUIC 或 CDN；确认服务器端口跳跃规则仍在 |
| CDN 节点不通 | 检查域名是否过期、Cloudflare 是否 Active、WebSockets 是否开启 |
| 延迟测试都超时但网页能开 | 测速 URL 被规则拦截或超时阈值太低，以实际访问为准 |
