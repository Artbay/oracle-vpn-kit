# 04 注意事项（汇总）

## 用途

- 仅用于**个人日常浏览**。**不要与其它业务共用这台机器的出口**。
- 遵守你所在地的法律法规，以及 Oracle Cloud、Cloudflare、DigitalPlat 的服务条款与可接受使用政策。

## 凭据与分享

- 订阅 URL、分享链接、二维码 = 账号密码：**只给自己的设备用，不转发、不截图发群、不贴到聊天/工单里**。
- 泄露后：换 `SUB_TOKEN`（必要时连同 UUID、Hy2/TUIC 密码、Reality 密钥一起轮换）→ 重新生成并发布 → 各设备删除旧节点后重新导入。
- **秘密不进 git**：`.env`、`out/`、`*.key`/`*.pem`/证书、cloudflared 的 `cert.pem` 和 `<隧道ID>.json` 都已在 `.gitignore`；提交前用 `git status` 看一眼，可配合秘密扫描工具。
- SSH 私钥只保存在你自己的电脑上，权限 600。

## 到期与回收

- **免费域名每年续期**：在 DigitalPlat Dashboard 看到期日，设到期前 90/60/30/7 天提醒；过期后 CDN 节点全部失效（见 [02](02_免费域名_DigitalPlat与Cloudflare.md)）。
- **Oracle 闲置回收**：Always Free 实例 7 天内 CPU（95 分位）、网络都低于 20% 可能被回收；账户 30 天闲置可能被视为弃用；回收后无法恢复（见 [01](01_免费服务器_甲骨文云.md)）。
- 不要无意中升级到 Pay As You Go；升级前设预算提醒。

## 网络封锁与换 IP

- 部分家宽会对 VPS IP **封 TCP**（UDP 往往仍通）：优先用 Hy2/TUIC，TCP 兜底用 CDN 节点。
- 需要换 IP 时：控制台把临时公网 IP 改为 No public IP 再改回 Ephemeral（会拿到新 IP）→ 改 `.env` 的 `VPS_IP` → 重新生成并发布订阅 → 客户端先切 DIRECT 再更新。CDN 节点不受换 IP 影响。
- 不要为了绕过限速而频繁换 IP 或叠加多层代理。

## 隐私与日志

- Xray 默认 `loglevel: warning`，`access.log` 会记录访问目标；如更在意隐私，可把 `access` 设为 `none` 或定期清理日志。
- Hysteria2 默认 `HYSTERIA_LOG_LEVEL=info`，TUIC `log_level: info`；可改为 `warn`/`error` 减少记录。
- 订阅服务是明文 HTTP，安全性完全依赖长随机路径；不要在不可信的网络上频繁更新订阅。

## 备份与回滚

- 脚本每次改文件前会备份为 `<文件>.bak-YYYYmmdd-HHMMSS`；升级、卸载、订阅的备份在 `/var/backups/oracle-vpn-kit/`（可用 `.env` 的 `BACKUP_DIR` 改）；回滚步骤见下文和 [方案.md 第 6 节](方案.md#6-回滚)。
- 自己保留一份 `.env` 的离线备份（加密存放），服务器被回收或重装时可用本仓库 + `.env` 原样重建。
- Cloudflare 里只动本方案新增的那一条 CNAME，**不改动已有的其它记录和设置**。

## 运维：升级与回滚

所有维护命令都在服务器上、仓库目录里执行。

### 一键部署 / 重新部署

```bash
bash scripts/deploy.sh --plan [--set KEY=VALUE ...]        # 只读：计划 + 预检，不改任何东西，无需 root
sudo bash scripts/deploy.sh --yes [--only ...|--skip ...]  # 执行；交互终端里可用 --apply（会要求输入 yes）
```

- **计划模式**（默认）：列出组件、脱敏后的配置（密码/UUID 只显示「已设置（N 位，已隐藏）」）、预检（root、系统、架构、systemd、外网、端口占用、主人需提供的值）以及每一步「是否修改系统」。退出码 0 = 预检通过，2 = 预检有 FAIL；都不会修改任何东西。
- **执行模式**：preflight → `gen_secrets.sh`（.env 不存在时创建，权限 600，不覆盖已有值）→ `prepare_host.sh` → xray → hy2 → 端口跳跃 → tuic → cdn（缺域名、缺 Cloudflare 授权证书且非交互时跳过并说明原因）→ 生成客户端文件 → 发布订阅 → `status.sh`。
- **日志**：`/var/log/oracle-vpn-kit/deploy-<时间>.log`（目录 700、文件 600，不含秘密；Cloudflare 授权步骤的输出只显示在终端）。
- **失败续跑**：出错即停，并打印失败的步骤、日志路径和续跑命令，例如 `sudo bash scripts/deploy.sh --yes --only hop,tuic,cdn,sub`。修好原因后执行即可；整条重跑也安全——没有变化时不会重写任何文件。
- **非交互**（给 AI/自动化用）：`--non-interactive`（无终端时自动开启）下执行必须带 `--yes`，表示主人已批准；需要浏览器授权的 cdn 步骤会被跳过。
- 改了 `.env` 某个值后，也可以用 `--only` 只重跑相关组件，例如 `sudo bash scripts/deploy.sh --yes --only hy2,hop,sub`（`clients` 和 `status` 每次都会跑）。

### 健康检查（只读）

```bash
sudo bash scripts/status.sh            # 全部检查，有 FAIL 时退出码为 1
sudo bash scripts/status.sh --quiet    # 只显示 WARN / FAIL 和汇总
sudo bash scripts/status.sh --no-net   # 跳过经 Cloudflare 的 CDN 回源检查
```

检查服务状态、监听端口（WS 只能在 127.0.0.1）、iptables 放行、端口跳跃规则是否在且已持久化、证书有效期、Xray 配置自检、订阅能否取回、订阅根目录是否会列出文件、隧道连接数、BBR、磁盘、内存。输出里**不含任何密码、UUID 或订阅 token**（token 只显示前 4 位），可以放心截图给自己排障，但仍不建议外发。

可以加到 crontab 每天跑一次，只在失败时提醒自己，例如 `0 9 * * * cd /path/to/kit && bash scripts/status.sh --quiet --no-net >/var/log/vpn-status.log 2>&1 || echo FAIL >> /var/log/vpn-status.log`。

### 升级核心

```bash
sudo bash scripts/update.sh --check          # 只看当前版本与最新版本
sudo bash scripts/update.sh xray             # 只升级 Xray
sudo bash scripts/update.sh hy2 tuic         # 升级多个
sudo bash scripts/update.sh all              # 全部（xray、hy2、tuic、cloudflared）
sudo bash scripts/update.sh --version v26.1.1 xray   # 指定版本（也用于降级）
```

每个核心的流程：查最新正式版 → 下载 → 按官方校验文件验 sha256（不通过即中止）→ 旧二进制备份到 `/var/backups/oracle-vpn-kit/bin/` →（Xray 先用新二进制自检现有配置，不通过不替换）→ 替换并重启 → **服务起不来自动回滚旧二进制** → 最后跑一遍 `status.sh`。cloudflared 通过官方 apt 源升级。

建议：一次只升级一个核心，确认客户端能用后再升下一个；大版本升级前看一眼该项目的 Release 说明里有没有配置格式变化。

### 手动回滚

```bash
ls /var/backups/oracle-vpn-kit/bin/                                  # 找到要回退的版本
sudo install -m 755 /var/backups/oracle-vpn-kit/bin/xray.<时间> /usr/local/bin/xray
sudo systemctl restart xray && sudo bash scripts/status.sh
```

hysteria、tuic-server 同理（目标路径 `/usr/local/bin/hysteria`、`/usr/local/bin/tuic-server`）。cloudflared：`apt-cache policy cloudflared` 查看可用版本，`sudo apt-get install cloudflared=<版本>`。配置文件回滚用同目录下的 `*.bak-时间戳`。

### 卸载

```bash
sudo bash scripts/uninstall.sh --dry-run          # 先看会执行哪些命令（不做任何修改）
sudo bash scripts/uninstall.sh tuic               # 只卸载某个组件：xray hy2 hopping tuic cloudflared sub
sudo bash scripts/uninstall.sh                    # 全部：停服务、删 unit、删本工具加的防火墙/跳跃规则
sudo bash scripts/uninstall.sh --purge            # 另外删除二进制、配置、证书、订阅目录（先打包备份）
```

- 只删除与 `.env` 端口**完全一致**的、本工具添加的规则；**不会动 SSH（22）**、BBR/swap 和其它任何防火墙规则。
- 如果 `XHTTP_PORT` 是 443 且机器上还有别的服务用 443，卸载 xray 前请先确认，或用组件参数跳过 xray。
- `--purge` 前会把要删的东西打包成 `/var/backups/oracle-vpn-kit/uninstall-<时间>.tar.gz`（权限 600，含私钥，注意保管）。
- Cloudflare 侧的隧道、DNS 记录和 `~/.cloudflared/cert.pem` 不会被自动删除，脚本会提示手动步骤；OCI 安全列表也需在控制台手动收回。
