# 04 注意事项（汇总）

## 用途

- 仅用于**个人日常浏览**。**不要与其它业务共用这台机器的出口**。
- 遵守你所在地的法律法规，以及 Oracle Cloud、Cloudflare、DigitalPlat 的服务条款与可接受使用政策。

## 凭据与分享

- 订阅 URL、分享链接、二维码 = 账号密码：**只给自己的设备用，不转发、不截图发群、不贴到聊天/工单里**。
- 泄露后：换 `SUB_TOKEN`（必要时连同 UUID、Hy2/TUIC 密码、Reality 密钥一起轮换）→ 重新生成并发布 → 各设备删除旧节点后重新导入。
- **秘密不进 git**：`.env`、`out/`、`*.key`/`*.pem`/证书、cloudflared 的 `cert.pem` 和 `<隧道ID>.json` 都已在 `.gitignore`；提交前用 `git status` 看一眼，可配合秘密扫描工具。
- SSH 私钥只保存在你自己的电脑上，权限 600。

## 到期与回收

- **免费域名每年续期**：在 DigitalPlat Dashboard 看到期日，设到期前 90/60/30/7 天提醒；过期后 CDN 节点全部失效（见 [02](02_免费域名_DigitalPlat与Cloudflare.md)）。
- **Oracle 闲置回收**：Always Free 实例 7 天内 CPU（95 分位）、网络都低于 20% 可能被回收；账户 30 天闲置可能被视为弃用；回收后无法恢复（见 [01](01_免费服务器_甲骨文云.md)）。
- 不要无意中升级到 Pay As You Go；升级前设预算提醒。

## 网络封锁与换 IP

- 部分家宽会对 VPS IP **封 TCP**（UDP 往往仍通）：优先用 Hy2/TUIC，TCP 兜底用 CDN 节点。
- 需要换 IP 时：控制台把临时公网 IP 改为 No public IP 再改回 Ephemeral（会拿到新 IP）→ 改 `.env` 的 `VPS_IP` → 重新生成并发布订阅 → 客户端先切 DIRECT 再更新。CDN 节点不受换 IP 影响。
- 不要为了绕过限速而频繁换 IP 或叠加多层代理。

## 隐私与日志

- Xray 默认 `loglevel: warning`，`access.log` 会记录访问目标；如更在意隐私，可把 `access` 设为 `none` 或定期清理日志。
- Hysteria2 默认 `HYSTERIA_LOG_LEVEL=info`，TUIC `log_level: info`；可改为 `warn`/`error` 减少记录。
- 订阅服务是明文 HTTP，安全性完全依赖长随机路径；不要在不可信的网络上频繁更新订阅。

## 备份与回滚

- 脚本每次改文件前会备份为 `<文件>.bak-YYYYmmdd-HHMMSS`；回滚步骤见 [方案.md 第 6 节](方案.md#6-回滚)。
- 自己保留一份 `.env` 的离线备份（加密存放），服务器被回收或重装时可用本仓库 + `.env` 原样重建。
- Cloudflare 里只动本方案新增的那一条 CNAME，**不改动已有的其它记录和设置**。
